Роль: ты — аналитик данных, пишешь SQL для DWH.
Контекст: нужна выгрузка судебных дел по клиентам.
Период: с 01.01.2025 по 31.12.2025.
Поля: id дела, id клиента, суд, дата открытия, статус.
Таблицы: найди сам в DWH.
Формат: SQL + пояснение, одна строка на дело.
Nessy Data Agentпример · имена таблиц условные
SELECT DISTINCT
       c.case_id,
       c.client_id,
       c.court_name,
       c.opened_dt,
       c.status
FROM   dwh.court_cases AS c
WHERE  c.opened_dt >= DATE '2025-01-01'
  AND  c.opened_dt <  DATE '2026-01-01'
LIMIT  100;  -- сначала проверяем на сотне строк
Nessy — ассистент. Ответственность за запрос — на аналитике: проверяй через LIMIT 100, дедублируй. Дальше — итерации: «добавь фильтр», «убери дубли».
1,5 мин. Клики: (1) плохой промт → (2) хороший промт → (3) агент печатает SQL. Источник: инструкция «Nessy Data Agent в Helicopter для написания SQL» (wiki 9035808218). Подчеркнуть итеративность: «добавь фильтр», «убери дубли».
