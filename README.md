# AI в BI — интерактивная презентация для BI-митапа

**Запуск:** откройте `AI-v-BI.html` в Chrome или Edge. Это один файл без внешних зависимостей: шрифты, QR-генератор и 3D-движок встроены внутрь, интернет не нужен.

Внутри 29 слайдов и 8 разделителей: общий доклад (Роман) и встроенная часть Степана про сбор требований. Фон — WebGL-сцена из 24 000 частиц, которая на каждом слайде собирается в новую форму: текст «AI в BI», ДНК-таймлайн, лестница зрелости из четырёх уровней, орбиты MCP, «Qwen → DeepSeek», «11 563», пайплайн MR, синтвейв-горизонт и другие. Частицы расступаются вокруг курсора мыши.

## Управление

| Клавиша | Действие |
|---|---|
| `→` `Space` `PgDn` / клик | дальше (сначала шаги внутри слайда) |
| `←` `PgUp` | назад |
| `P` | **пульт спикера** в отдельном окне: заметки, таймер 30:00, следующий слайд, список. Пульт тоже листает слайды |
| `N` | заметки поверх слайда (их видят зрители!) |
| `O` / `Esc` | обзор всех слайдов |
| `K` | короткая версия на 15 минут (§8 плана) |
| `F` | полный экран |
| `B` | затемнить экран |
| `L` | лёгкий режим частиц: для слабого ПК и шаринга. Включается и сам, если FPS проседает |
| `↑` `↓` `⏎` `1–9` `R` | выбор и перезапуск в терминальных демо (на этих слайдах листать — только `→` / пробел) |
| цифры + `Enter` | перейти к слайду N |
| `H` / `?` | справка |

Кликеры (PgUp/PgDn) работают. Если в Zoom/Teams вы показываете одно окно, пульт откройте на втором мониторе.

## Что заполнить `[СОБРАТЬ]`

1. **Имя, команда, дата, контакт, ссылка для финального QR** — объект `CONFIG` в начале `src/app.js`. После правки запустите `node build.mjs`.
2. **Скриншоты «было/стало» (слайд 19) и фото (слайд 2)** — перетащите картинку прямо на рамку в браузере. Она сохранится в этом браузере; `Alt`+клик по рамке удалит её. Второй вариант — положить файлы рядом с HTML и прописать пути в `CONFIG.shots`.
3. **Состав BI-пака** — плейсхолдер в `src/index.html` (слайд «Как скилл попадает в BI-пак»).
4. **Сценарий демо proteus-echarts-builder** — иллюстрация; сверить шаги с реальным выводом скилла (`ECH.FLOW` в `src/demos.js`).

## Интерактивы

- **Флоу BI (слайд 4):** девять этапов жизни отчёта с доски команды — кольца из частиц в цветах доски и петля «сбор ОС → бизнес-анализ»; клики показывают, где этапы уже AI-изированы и какие агентские среды работают везде. Тот же флоу повторяется на разделителях (горят этапы раздела) и в HUD справа сверху.
- **Всё упирается в контекст:** источники контекста стекаются в Nessy Data Agent; клик — «что на входе, то и на выходе».
- **Nessy → DeepSeek:** частицы «Qwen» рассыпаются и собираются в «DeepSeek».
- **Флоу × наши скиллы:** какие этапы уже закрывают скиллы BI-пака, затем передача слова Степану.
- **Часть Степана:** интерактивный чек-лист из 25 вопросов (клик по блоку) и терминальное демо `bi-requirements-gather` с настоящими ветками.
- **proteus-echarts-builder:** частицы HTML-макет → база данных → 3D-виджет, терминальное демо в том же стиле и живой виджет «было/стало» на синтетических данных.

## Структура

```
AI-v-BI.html       ← собранный файл, его и открывать
src/index.html     ← слайды и заметки спикера (<aside class="notes">)
src/styles.css     ← оформление
src/app.js         ← CONFIG, сцены частиц, навигация, пульт, виджет
src/demos.js       ← терминальные демо и чек-лист 25 вопросов
src/engine.js      ← WebGL2-движок морфинга частиц
src/shapes.js      ← генераторы 3D-форм
src/vendor/        ← встроенные шрифты (OFL) и qrcode-generator (MIT)
build.mjs          ← node build.mjs — собрать src/ в один HTML
```

Для правок удобно открыть `src/index.html` напрямую: он работает без сборки.
